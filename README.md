# Navbar Component — Sojib.dev

A clean and responsive navigation bar for my personal portfolio website.

## Navigation Links

- **Sojib.dev** — Home
- **Experience**
- **Skills**
- **Projects**
- **Contact**
- **Let's Talk** — Contact section

## Features

- Smooth navigation to page sections
- Responsive navbar design
- Home, Experience, Skills, Projects, and Contact links
- Let's Talk call-to-action button
- Simple and modern UI

## Technologies Used

- Next.js
- React.js
- TypeScript
- Tailwind CSS

## Section IDs

The navbar links navigate to these sections:

- `#home`
- `#experience`
- `#skills`
- `#projects`
- `#contact`

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
